# Code of conduct

seedreach follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it; this page summarises how it applies here.

## In short

- Be kind and assume good intent. Many contributors here are students opening their first pull request.
- Critique code and ideas, never people.
- No harassment, discrimination, personal attacks, or sharing anyone's private information.
- This project exists to help people reach out respectfully. Don't use it, or this repository, to spam
  or harass anyone.

## Scope

This applies in issues, pull requests, Discussions, and anywhere you represent the project.

## Reporting

If someone's behaviour makes you uncomfortable, email **poushalibhattacharyya02@gmail.com** with
"seedreach conduct" in the subject. Reports are kept confidential. Responses follow the Covenant's
enforcement guidelines, from a private warning up to a ban from the project.
